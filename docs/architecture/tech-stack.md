# Tech Stack

## Recommended Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- GSAP ScrollTrigger
- Motion
- D3
- shadcn/ui selectively
- Lucide icons

## Supporting Tools

- MDX or typed data files for content
- Next metadata API
- Next image optimization
- Vercel deployment
- Playwright for visual verification

## Why This Stack

Next.js gives professional routing, SEO, metadata, and deployment quality.

GSAP handles complex authored scroll scenes better than hand-rolled code.

Motion handles tactile component-level animation cleanly.

D3 handles timeline scales and data-driven visualizations.

Tailwind gives speed and consistency without forcing template-like visuals.

shadcn/ui gives accessibility foundations for tabs, dialogs, tooltips, and command palette, but components should be heavily styled to match the premium direction.
