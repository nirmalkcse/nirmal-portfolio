# Validated Decisions

These decisions are accepted and should guide future sessions.

## Concept

- **Cinematic Engineering Dossier** is an internal creative direction.
- Do not use this phrase as heavy public-facing copy unless it feels natural in a small hidden/craft note.

## Structure

- Build a cinematic homepage plus professional deep-dive pages.
- Do not make the whole portfolio a single long page only.

## Role Gateway

- The site opens with the cinematic hero first.
- Role selection appears as a soft intro section after the hero.
- Role selection should not block access.
- Role can be changed later from a subtle control.

## Visual Direction

- Apple-like minimal premium with luxury details.
- Start with the proposed luxury palette and refine during design.
- Avoid noisy neon, cartoon avatars, heavy 3D, and fake terminal theatrics.

## Signature Motifs

- Use **Gold Thread** as the repeated visual memory cue.
- Use **Proof Graph** as the distinctive credibility system.
- Use both the `NK Gold Thread Monogram` and full `Nirmal Kumar` wordmark.

## Motion

- Cinematic in hero and timeline.
- Restrained elsewhere.
- Motion must clarify, confirm, or reward.
- Reduced-motion mode is required.
