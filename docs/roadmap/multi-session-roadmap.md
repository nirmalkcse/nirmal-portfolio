## Workflow

At the end of every implementation session:

1. Update the relevant session file.
2. Update [Progress Tracker](../tracking/progress-tracker.md).
3. Add important learnings to [Session Learnings](../learnings/session-learnings.md).
4. Add major decisions to [Decision Log](../learnings/decision-log.md).
5. Add unresolved questions to the next session file.
