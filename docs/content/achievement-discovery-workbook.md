## How To Use This

For each achievement, fill only what you remember first. Do not worry about wording. After the raw memory is captured, move it through the proof ladder:

1. Raw memory: what happened, in plain words.
2. Facts to verify: dates, names, scope, team size, exact outcome, public-safety boundary.
3. Evidence: screenshot, email, Teams message, certificate, demo deck, Jira, release note, Git history, public link, manager note, client note.
4. Public-safe wording: what can be said without exposing client, company, internal product, or private data.
5. Portfolio destination: Home, Work, project detail, timeline, resume, profile, documents, LinkedIn.

## Claim Safety Levels

| Level | Use When | Public Wording Pattern |
|---|---|---|
| Public verified | Public link or approved proof exists | Name the client/event/product directly if approved. |
| Public-safe anonymized | Real achievement exists but details are private | Use industry, role, technology, and outcome without names. |
| Internal proof only | Evidence exists but cannot be published | Use cautious wording and say details are client-safe/anonymized. |
| Needs confirmation | Memory is promising but incomplete | Keep in this workbook; do not publish yet. |
