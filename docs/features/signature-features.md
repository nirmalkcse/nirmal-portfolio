# Signature Features

These features define the portfolio and should guide implementation priorities.

## P0 Features

### Personal Brand Mark And Wordmark

Use the `NK Gold Thread Monogram` plus `Nirmal Kumar` wordmark across the full experience.

### Cinematic Identity Reveal

The site opens with the premium identity reveal.

Sequence idea:

1. Dark field with faint gold line.
2. Name appears with restrained typography.
3. Hybrid role phrase resolves.
4. Profile/certification/project proof nodes appear.
5. Lines connect into a refined system diagram.
6. CTAs appear.

### Soft Role Gateway

Appears after the hero as "Choose your lens."

Roles:

- Recruiter
- Engineer
- Leader
- Explorer

### Gold Thread

A thin gold progress line that travels through the page and lights up sections.

### Proof Graph

Connect skills to evidence.

Example:

- Azure -> Microsoft credential -> cloud project -> resume bullet
- Databricks -> credential -> data engineering project -> architecture diagram
- Python -> ML project -> GitHub repo -> measurable outcome

### Career Timeline Instrument

Scroll-driven timeline with tracks:

- Education
- Work
- Certifications
- Projects
- Currently exploring

### Certification Console

Credential console with filters, verification links, provider grouping, and detail drawers.

### Project Case Files

Projects open into professional case files:

- Problem
- Context
- Architecture
- Stack
- Decisions
- Tradeoffs
- Impact
- Links
- Future improvements
