# Advanced Bells And Whistles Backlog

These are optional but intentionally ambitious. They should be introduced after the core site feels polished and professional.

## Professional Utility Features

### Personalized Document Builder

Visitor selects a target lens and receives the most relevant resume or portfolio packet.

Possible packets:

- Recruiter packet
- Data Engineer resume
- AI / ML Engineer resume
- Cloud Engineer resume
- Project case-study PDF
- Certification proof packet
- One-page executive summary

### Role-Specific Share Links

Examples:

- `?view=recruiter`
- `/for/engineer`
- `/for/leader`

### Credential Proof Packet

Downloadable PDF or page collecting:

- Certificates
- Verification links
- Related skills
- Related projects

### Project Case-Study Export

Selected projects can export as polished PDF one-pagers.

### Contact Card Download

`.vcf` contact card with LinkedIn, GitHub, email, and portfolio.

### Recruiter Quick Copy

One-click copy of a short professional summary.

### Interview Prep Mode

Surfaces:

- Key projects
- Architecture diagrams
- Resume bullets
- Proof links
- Certifications

### Contact Intent Form

Optional lightweight form:

- Hiring
- Collaboration
- Referral
- Networking

### Print-Perfect Portfolio Mode

Clean print stylesheet for resume, project, certification, and document pages.

## Hidden Delight And Easter Eggs

### Dossier Vault

Hidden command-palette entry revealing experiments, learning logs, or currently exploring ideas.

### Gold Thread Unlock

After scrolling the full page, the Gold Thread completes the NK mark in the footer.

### Console Commands

Tasteful commands:

- `show proof`
- `open vault`
- `timeline focus`
- `verify credentials`

### Keyboard Shortcut Easter Egg

Optional hidden shortcut that reveals a subtle systems-map mode.

### LeetCode Pulse

Small tasteful visual signal near the LeetCode CTA.

### Hidden Build Notes

Behind-the-scenes craft note explaining how the portfolio was designed and engineered.

### Signature Loading Moment

The NK mark draws itself once, then gets out of the way.

### Achievement Stamp Animation

Credentials receive a restrained verification stamp when opened.

## Guardrails

- Easter eggs must be opt-in or hidden.
- No joke should weaken professional credibility.
- No interaction should block recruiters from getting the resume quickly.
- Every advanced feature must have reduced-motion and mobile-friendly behavior.
