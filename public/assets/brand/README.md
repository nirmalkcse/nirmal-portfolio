## Color Tokens

- Obsidian: `#070707`
- Ivory: `#F4EFE4`
- Antique gold: `#B9974A`

## Production Notes

- The monogram is intentionally unenclosed for primary brand use.
- The vertical antique-gold line is the Gold Thread memory cue.
- One-color variants preserve the thinner thread spine by weight, not by color.
- The wordmark uses a vector custom `N` plus system-font text to stay aligned with the typography strategy and avoid embedding licensed font files.
- Future app implementation should consume these assets as files and should not redraw the mark inside UI components.
